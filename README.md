# SimpleWorth（简值）

一款参考 Apple Fitness 视觉语言的记账类 iOS App 原型，包含四个底部 Tab：`支出`、`收入`、`统计`、`小金库`。

## 功能

- 支出：丰富生活消费分类 + 图标网格 + 最近支出
- 收入：多来源收入分类 + 图标网格 + 最近收入
- 统计：月度收支图表 + 分类占比环形图 + 关键指标卡片
- 小金库：小目标进度、总进度环、最近存入记录

## 技术栈

- SwiftUI
- Charts
- XcodeGen（生成 Xcode 工程）

## 启动

```bash
xcodegen generate
open SimpleWorth.xcodeproj
```
